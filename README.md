## 📌 Descripción del Proyecto
Este proyecto demuestra la arquitectura cloud integral desarrollada durante el Azure Bootcamp. Incluye la orquestación de servicios en Azure, automatización de la infraestructura como código (IaC), pipelines de CI/CD, prácticas de seguridad y la integración de agentes de Inteligencia Artificial.

---

## 🛠️ Módulos y Temas Cubiertos

### 1. Gobierno y Redes en Azure
- **Resource Groups & RBAC:** Estructura lógica de recursos y control de acceso basado en roles (*Least Privilege*).
- **Azure Virtual Networks (VNet) & NSG:** Configuración de subredes y reglas de seguridad de red.

### 2. Cómputo y Almacenamiento
- **Azure App Service:** Hospedaje de aplicaciones web.
- **Azure Storage Accounts:** Almacenamiento de blobs para archivos estáticos.

### 3. Seguridad y Monitoreo
- **Azure Key Vault:** Gestión centralizada y cifrada de secretos y cadenas de conexión.
- **Azure Monitor & Application Insights:** Recolección de telemetría y alertas operativas.

### 4. Infraestructura como Código (IaC) & DevOps
- **Azure Bicep / ARM Templates:** Aprovisionamiento declarativo de recursos.
- **CI/CD con GitHub Actions / Azure DevOps:** Pipeline automatizado de validación y despliegue continuo.

### 5. Inteligencia Artificial & Agentes (Azure AI Foundry)
- **Azure AI Foundry:** Integración de modelos del catálogo de IA Generativa.
- **Retrieval-Augmented Generation (RAG) & LangGraph:** Orquestación de agentes agénticos conectados a bases de conocimiento.
